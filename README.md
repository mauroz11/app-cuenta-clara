# Cuenta Clara Colombia

Aplicación web estática para diligenciar, firmar y generar en PDF una cuenta de cobro para Colombia.

## Ejecutar localmente

```bash
npx serve .
```

## Publicar en Vercel

1. Sube esta carpeta a un repositorio de GitHub.
2. En Vercel selecciona **Add New → Project** e importa el repositorio.
3. En la configuración deja el proyecto como **Other** (sitio estático) y pulsa **Deploy**.

No requiere variables de entorno ni servidor: los datos permanecen en el navegador de la persona usuaria.

## Alcance tributario

Una cuenta de cobro no reemplaza la factura de venta. La app avisa expresamente que solo debe usarse si quien cobra no está obligado a facturar; la condición depende del caso concreto. Consulta la información de la DIAN y, ante duda, a un contador.
